# Contexte — site_st

## Objectif (immuable sauf décision explicite)
Portail vers l'IA éco-responsable et humaniste pour serenia-tech.fr : un site qui ressemble à une appli (cartes à toucher, animations, parcours guidé) pour découvrir ce qu'est l'IA éco-responsable et l'humanisme numérique (l'IA au service de l'autonomie humaine). But : référence ; public : les associations (positionnement validé le 2026-11-03). Il intègre le contenu du site V2, réorganisé et réécrit avec l'utilisateur.

## Stack / contraintes techniques (stable, rarement modifié)
Stack de diffusion conservée : 11ty (site statique), HTML/CSS/JS, Express sur Render (contact non relié) ; hébergeur : Vercel retenu le 2026-11-14 (`vercel.json`, build `npm run build`, sortie `dist/`) ; Netlify écarté (`netlify.toml` conservé). Équilibre à trouver entre immersion (appli) et référencement classique + moteurs IA. Pas de PWA prévue. Mobile-first puis PC/télé.
