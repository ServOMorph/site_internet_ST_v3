# Contexte — site_st

## Objectif (immuable sauf décision explicite)
Portail vers l'IA éco-responsable et humaniste pour serenia-tech.fr : un site qui ressemble à une appli (cartes à toucher, animations, parcours guidé) pour découvrir ce qu'est l'IA éco-responsable et l'humanisme numérique (l'IA au service de l'autonomie humaine). But : référence ; public : grand public. Il intègre le contenu du site V2, réorganisé et réécrit avec l'utilisateur.

## Stack / contraintes techniques (stable, rarement modifié)
Stack de diffusion conservée : 11ty (site statique), HTML/CSS/JS, Express sur Render (contact), Vercel (prévu) ; Netlify demandé le 2026-10-24 (`netlify.toml`, build `npm run build`, publication `dist/`), choix d'hébergeur à trancher. Équilibre à trouver entre immersion (appli) et référencement classique + moteurs IA. Pas de PWA prévue. Mobile-first puis PC/télé.
